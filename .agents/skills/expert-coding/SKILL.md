# Habilidad de Programación Experta

Al escribir o revisar código, sigue estas directrices:

1. **Modularidad**: Diseña funciones y clases con una única responsabilidad.
2. **Manejo de Errores**: Asegura el control correcto de excepciones y casos límite.
3. **Eficiencia y Estilo**: Escribe código limpio, documentado y optimiza la complejidad de ejecución.
4. **Pruebas**: Genera pruebas unitarias para asegurar la estabilidad del software.
