# Habilidad de Diseño UX/UI

Al diseñar o sugerir interfaces, sigue estas directrices:

1. **Enfoque en el usuario**: Prioriza la usabilidad, consistencia y accesibilidad (normas WCAG).
2. **Jerarquía Visual**: Define claramente la tipografía, espacios, colores y el contraste de los elementos.
3. **Estructura limpia**: Organiza los flujos de usuario de forma lógica y modular.
